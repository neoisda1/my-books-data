# My Books data

Books for the My Books section of the Kids Dua app. The app doesn't bundle
them: it downloads each one when a reader asks for it, through jsDelivr, from
a tag of this repository.

## Tafsir al-Mizan (English), AI translation

`almizan/` holds Tafsir al-Mizan by Allamah Sayyid Muhammad Husayn
Tabataba'i, in the English translation made by **Furqan Apps** with
artificial intelligence from the original Arabic. There is one gzipped JSON
file per surah, plus `almizan_000` for the introduction.

In Furqan Apps' own words, the translation "has been generated from the
original Arabic text (sourced from lib.rafed.net) using advanced Artificial
Intelligence technology", "there may be errors, omissions, or inaccuracies in
the text", and it "should be used with appropriate discretion and scholarly
verification when needed. It is not a substitute for studying under qualified
teachers or consulting traditional scholarly works."

**What was done to the text.** It was divided into daily reading passages,
and its Markdown formatting was taken off. Nine stray lines that are not part
of the translation were removed: leftovers from the AI process, such as
"thoughtful" and "Standard cleaning and formatting applied. No commentary
added.", and one heading duplicated inside a sentence. No wording of the
translation was changed. Corrections to the translation itself belong with
Furqan Apps (usersupport@furqan.app).

These files are generated by `generate_reading_books.py` in the app's
repository. Don't edit them by hand. A changed book is published under a new
tag; tags are never moved.
